Tentang Saya

Saya menempuh pendidikan S1 Teknik Informatika di Universitas Suryakancana. Latar belakang yang memiliki minat dan kemampuan di bidang teknologi informasi, khususnya pengembangan perangkat lunak, pemrograman, perancangan sistem, serta desain antarmuka UI/UX. Memiliki pengetahuan dalam pengembangan aplikasi berbasis web, pengelolaan basis data, perancangan wireframe dan prototype, serta pemodelan sistem menggunakan UML.

Saya terbiasa menggunakan berbagai tools teknologi dan produktivitas, seperti Visual Studio Code, Laravel, PHP, MySQL, Git/GitHub, Figma, Microsoft Word, dan Microsoft Excel. Saya juga memiliki pengalaman dalam mengembangkan sistem informasi berbasis web serta menerapkan perancangan UI/UX dan pengelolaan data dalam proses pengembangan aplikasi.

Selain latar belakang di bidang teknologi, saya memiliki pengalaman kerja di bidang administrasi dan operasional yang membantu saya terbiasa bekerja secara teliti, terstruktur, serta mampu mengelola data dan dokumen. Saya mampu bekerja secara individu maupun dalam tim, mudah mempelajari hal baru, dan memiliki motivasi untuk terus mengembangkan kemampuan serta memberikan kontribusi melalui pemanfaatan teknologi.
